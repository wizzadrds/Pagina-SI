Auditoría de certificados digitales

Una auditoría de certificados digitales en una pasarela de pago permite comprobar que la transmisión de datos financieros sensibles, como los datos de una tarjeta, se realiza mediante una conexión cifrada y segura.

También se debe comprobar la seguridad de la pasarela de pago y los requisitos que le sean aplicables, como PCI-DSS.

¿Qué son los certificados SSL/TLS?

Los certificados SSL/TLS permiten establecer una conexión segura entre el navegador del usuario y la página web.

Funciones de los certificados SSL/TLS

  • Cifrar los datos que se envían por Internet.
  • Proteger la información y las contraseñas de los usuarios durante la transmisión.
  • Comprobar que el certificado corresponde al dominio correcto.

Lista de comprobación de la auditoría

  • Comprobar que la página utiliza HTTPS.
  • Verificar que el certificado procede de una entidad de confianza.
  • Comprobar que el certificado no está caducado.
  • Comprobar que el certificado corresponde al dominio de la tienda.
  • Comprobar que la pasarela de pago utiliza una conexión segura.

Resultado de la auditoría

Estado: HTTPS activo en la dirección publicada mediante GitHub Pages.

La página se puede visitar mediante una conexión HTTPS. Queda pendiente verificar por separado la entidad emisora, la fecha de caducidad y la correspondencia del certificado con el dominio, así como revisar una pasarela de pago real.
